# Блоки в редакторской сетке: краткое описание

**Интеграция в сетку.** Главная собирается из типизированного списка слотов `GridItemConfig`. Помимо `article` появились два типа: `product-showcase` и `webinar-showcase`. У каждого слота есть `id`, ширина `span` в 12-колоночной сетке (`full`, `half`, `third`, `quarter`) и собственные `settings`; порядок в списке — порядок на странице. Страница просто сопоставляет тип слота с компонентом, поэтому блоки ставятся в любое место сетки, как обычная карточка. Ошибочный слот пропускается, страница не ломается.

**Что настраивает редакция.**

- Витрина: `{ mode: 'rotation' }` — продукт дня, или `{ mode: 'pinned', productId }` — закрепить продукт.
- Вебинары: `{ rule: 'upcoming-then-recent', limit, series? }` — ближайшие, затем недавние прошедшие (можно ограничить серией, например только The Bell.Tech), или `{ rule: 'manual', webinarIds }` — конкретные вебинары в заданном порядке.
- Вид вебинаров: `feature` — крупная карточка 1/2 с обложкой, датой, статусом и CTA; `list` — строка ближайших и прошедших вебинаров.
- Вид статьи (широкая обложка, карточка, текстовая строка), заголовок блока и ширина каждого слота.

**Как выбирается продукт.** Фиксированная последовательность `Новости → Tech → Invest → Unlimited` без продуктов, закреплённых на этой же странице; индекс = номер календарного дня по Москве от 01.01.2026 по модулю размера этого списка. Весь день показывается один продукт, после полуночи по Москве — следующий, без перезагрузки. Закреплённый продукт важнее ротации, и на одной странице продукт не повторяется: при закреплённом Unlimited продукт дня идёт по кругу Новости → Tech → Invest. Неизвестный закреплённый продукт → ротация.

**Как определяется содержимое блоков.** Витрина — компактная карточка 1/3: название, подзаголовок и предложение из каталога (пробный тариф, если есть, иначе месячный) и знает, оформлена ли уже подписка. Вебинары: статус «скоро / эфир начался / прошёл» считается от текущего времени (длительность не опубликована, поэтому «эфир начался» держится до полуночи по Москве, а не до выдуманного конца); CTA зависит от прав читателя: до начала без права — «Получить доступ» с тарифами, которые его дают (включая Unlimited); есть право — «Доступ уже включён в вашу подписку»; после начала доступ к эфиру не продаётся, карточка ведёт на страницу события; прошёл — запись, только если её публикация подтверждена; внешнее членство (The Chat) — ссылка на сайт клуба.
